# Instructions

This folder contains benchmarks based on PyPSA-Eur. The benchmarks can be generated by following these steps:

- Install Docker on your machine.
- Build and run the Docker container containing all dependencies required to generate the benchmarks:
  ```sh
  cd solver-benchmark/benchmarks/pypsa/
  docker build --no-cache --platform=linux/amd64 -t pypsa-eur-image .
  docker run -it --network host pypsa-eur-image
  ```

- Inside the Docker container, run the benchmark generation script:
  ```sh
  pixi shell
  python generate.py --benchmark_name pypsa-eur-elec --configuration pypsa-eur-elec --clusters 50 --time_resolutions 168h --output_dir /tmp/ --file_extension .mps
  ```

  The `--benchmark_name` argument accepts:
  ```
  pypsa-eur-elec
  pypsa-eur-sec
  ```

  The `--configuration` argument selects one of the available benchmark configurations:
  ```
  pypsa-eur-elec
  pypsa-eur-elec-dfp
  pypsa-eur-elec-trex_copt
  pypsa-eur-elec-trex_copt-dfp
  pypsa-eur-elec-trex_copt-uc
  pypsa-eur-elec-trex_copt-uc-dfp
  pypsa-eur-elec-trex_vopt
  pypsa-eur-elec-trex_vopt-dfp
  pypsa-eur-elec-trex_vopt-uc
  pypsa-eur-elec-trex_vopt-uc-dfp
  pypsa-eur-elec-uc
  pypsa-eur-elec-uc-dfp
  pypsa-eur-sec
  pypsa-eur-sec-trex_copt
  pypsa-eur-sec-trex_vopt
  ```

  Use `--clusters` and `--time_resolutions` to specify the spatial and temporal resolutions. Multiple values can be provided for each argument.

  To generate benchmarks for Germany instead of Europe, add `--germany`. The generated instances will use the `pypsa-de-*` prefix.

- The generated benchmark files are saved in the specified output directory:
  ```
  pypsa-eur-elec-50-168h.mps
  pypsa-eur-elec-50-168h.nc
  pypsa-eur-elec-50-168h.yaml
  ```

The generator uses the upstream PyPSA-Eur workflow to build the network up to `compose_network`. The `export_model.py` script then prepares the network, constructs the Linopy optimization model, and exports it without solving. No patches to PyPSA-Eur or custom Linopy versions are required.

> If the PyPSA-Eur workflow fails during the retrieval of public data, please restart the workflow.
